## 📈 Data Visualization in Python

Data visualization helps convert raw data into **visual insights**.
It makes patterns, trends, and outliers easy to understand.

Python’s two most popular libraries:
- **Matplotlib** → core plotting library
- **Seaborn** → high-level, statistical visuals (built on Matplotlib)

---

## 🔹 Why Data Visualization?

- Understand data quickly
- Identify trends and patterns
- Communicate insights clearly
- Support data-driven decisions

---

## 🔹 Matplotlib vs Seaborn

| Feature | Matplotlib | Seaborn |
|-------|------------|---------|
| Level | Low-level | High-level |
| Control | Very high | Easy defaults |
| Best for | Custom plots | Statistical plots |
| Learning curve | Medium | Easy |

---

## 🔹 Common Plot Types

- Line plot
- Bar chart
- Scatter plot
- Histogram
- Box plot
